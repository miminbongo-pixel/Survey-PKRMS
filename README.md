# Struktur modul inti

Folder ini disiapkan untuk pengembangan lanjutan:
- coordinates: pemilihan CRS, PROJ, zona UTM Indonesia.
- project: metadata dan penyimpanan proyek.
- map: MapLibre dan pengelolaan kamera peta (`MapLibreConfig`, `GeoMapController`).
- storage: akses berkas Android.
- database: SQLite/GeoPackage.
- raster: GDAL, GeoTIFF, dan ECW SDK.
- vector: SHP, KML/KMZ, GPX, GeoJSON.
